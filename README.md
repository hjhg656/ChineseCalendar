# 历历在目 2.7

按小历（TinyCal 3.13.5）的界面与功能重建的中国农历日历 App，SwiftUI + WidgetKit。

## 界面（按小历截图与反编译规格）

- 动效（2.1 新增）：翻月时月历上下滑进滑出，点某日详情从底部滑上来、月历淡显，选年月、回今天、只显示本周、字号和面板尺寸变化都有平滑过渡。
- 贴合小历截图（2.2）：月视图默认不显示周数列；日详情去掉关闭叉（再点一次当天收起）、没内容时不显示空行；年月选择器改成内嵌面板（不是弹窗），底部四行还留着；底部图标改成描边样式。
- 实测对色对尺寸（2.3）：对着小历真机截图逐像素取色量尺寸——红 #EA545D、标题/数字 #404040、副行 #A6A6A6、节日蓝灰 #708090、蓝标签 #1070C0、事件蓝点 #0EA5E9；标题 23pt、星期头 14pt、日期数字 20pt、副行 10pt、今天红圆直径 36pt、行距 42pt；副行改成浅灰（之前是深色，不对）；底部图标改成灰色（之前是红色，不对）；小组件同款字号颜色，红圆/红竖线/休胶囊改用实测红，透明背景保留；动效按距离分时长，减弱动态效果打开时全部关掉。
- 详情收紧 + 随便点都能关（2.4）：日详情去掉撑大的 Spacer，卡片多高详情就多高，月历紧贴在下面（之前详情里一个空 Spacer 把月历顶下去一大截）；点空白处（月历和底部四行之间的空地、星期头）就关掉详情，跟原版一样，点某天切换、再点一次当天也关；修了三个截图里露出来的 bug：干支年算错了——Foundation 中国农历的 year 是黄帝纪元（2026 年对应 4663），之前直接拿来算干支会把 2026 年算成癸卯（兔）年，现在按公历年 + 春节分界推导，11 月正确显示丙午（马）年（主 App 和小组件一起修）；年月选择器点“确定”不再把日期重置成 1 号（之前标题的周数会跳到月初那周，显示 44 而不是 46），现在保持当月的几号；“国际科学与和平周”之前漏了 `*` 标记，会跑到月视图格子里抢农历小字的位置，现在只在日详情里出现。
- 设置终于生效（2.5）：之前颜色是静态读的，设置里改完主界面不刷新——现在 8 个颜色都用 @AppStorage 观察，改完立刻变；“默认展开今日”之前只存了开关没接线，现在打开 App 第一次就展开今天的日详情；“通知中心背景”那行删了（它从来没起过作用）；小组件改颜色修好了：以前小组件的颜色存在 App Groups 共享设置里，但免费签名没有 App Groups 权限，小组件根本读不到 App 的设置，所以怎么改都没反应。现在小组件改用系统自带的配置——桌面长按小组件 → 编辑小组件，可以选透明还是主题色、换主题色（14 个预设，和 App 里颜色选择器同一套）、调不透明度，不需要任何权限；主题色太浅（白、黄、柠檬）时字自动换成深色，不会白底白字看不清。
- 节假日接口接上了（2.6）：内置表只到 2027 年，以后不用等 App 更新——“更新节日推送”（设置里和桌面长按图标的快捷操作都是）现在真的去拉免费接口 holiday.ailcc.com（不用 key、不用注册），一次拉下一年（12 次请求，远没到每分钟 31 次的限额），拉到了存本地，月历的休/班就按新数据走；2028 年官方通知还没公布，现在点会提示“还没公布，先用内置表”，不会把好好的数据覆盖掉；内置表（2025–2027）永远保留当兜底。接口是个人业余项目，只认它的 type 字段分类（0 工作日、1 周末、2 节日、3 调休放假、4 补班），周末绝不当成“休”。
- 改名 + 图标（2.7）：App 正式改名“历历在目”（桌面显示名、关于页、分享文案都改了，内部包名还是 ChineseCalendar，不影响安装和签名）；图标是红底白“历”字 + 右下角一个小白点（今天），1024 大图 + 13 个尺寸都做进 Assets.xcassets 了。还有：2.5 把小组件改成系统配置（AppIntent）之后，之前加在桌面的旧小组件会一直停在占位图上——不是代码坏了，是旧实例的配置对不上，装好 2.7 后把小组件删掉重新加一个就好了。
- 月视图：标题 `2026 / 11 · 46`（年 / 月 · 第几周），左右箭头切月（长按切年），点标题打开年月选择器（2016–2036 + 1–12 月，当前年下有小红三角），双击标题回当月；左右滑动切月。
- 每格两行字：公历大字 + 农历/节日名小字；今天红色实心圆；节日名用蓝灰色字代替农历；事件小圆点画在日期下方（系统事件按日历颜色）；休/班在格子右上角小上标字。
- 周视图：只显示本周（一行）。
- 日详情：点某日后出现三行蓝标签卡（公历：`11月18日(2天后) 第46周`；农历：`丙午(马)年 十月初十`；事件：`+ 添加事件`），下面是节日/系统日程/提醒列表，月历淡显在下面，选中日黑色加粗。
- 底部固定四行：颜色 / 布局 / 偏好设置 / 其他，点开设置面板定位到对应分组。
- 小组件：小尺寸是今天；中尺寸是一周横排 + 底部信息行（红竖线 + `11月16日 第46周 丙午(马)年 十月 初八`），点某天打开 App 跳到那天。

## 设置

- 颜色 8 行（主题背景、一般日期、周末日期、节日日期、当前日期、系统事件、加班日期、休假日期），点开颜色选择器（14 个预设色 + 自定义），改完立刻生效。
- 布局 4 个滑杆：面板宽度、面板高度、元素大小、面板位置。
- 偏好设置：事件管理（选哪些系统日历/提醒列表显示）、使用系统事件颜色、显示周数、按键音效、显示系统事件、显示法定节假日、周首日、只显示本周、默认展开今日、隐藏非本月日期、使用更粗的字体、接收节假日推送、节假日推送时间、更新节日推送、开启 iCloud 同步（暂不支持）、显示副标题、显示已完成的提醒事项。
- 小组件：桌面长按小组件 → 编辑小组件，选透明还是主题色、换主题色、调不透明度（小组件自己的配置，不靠 App Groups；App 里设置页的小组件分组只放说明和刷新按钮）。
- 其他：清除缓存、还原所有设置、联系我们、赞美历历在目、关于历历在目。
- 桌面快捷操作（长按图标）：复制今天、查看今天、更新节日推送；深链 `chinesecalendar://年/月/日`。

## 数据

- 农历用 iPhone 自带的中国农历换算；干支年与生肖按农历年算（春节前算上一年）。
- 节日：公历/农历节日 + 周节日（国际科学与和平周）+ 24 节气（2025–2027 年日期表）。带 `*` 的次要节日（如世界人权日、南京大屠杀纪念日）月视图不显示，只在日详情出现。
- 法定节假日与休/班：2025 年国办发明电〔2024〕12 号、2026 年国办发明电〔2025〕7 号、2027 年国办发明电〔2026〕10 号（均已对照通知原文核对）。

## 做不到的

iCloud 同步、节日推送服务器、微信分享、Apple Watch 端、通知中心旧小组件（DayExt/EventExt）、Spotlight 搜索扩展——这些要么需要付费开发者账号/第三方注册，要么是已废弃的旧扩展，这个版本没有。

## 打包

GitHub Actions workflow（`.github/workflows/build-ipa.yml`）在免费 macOS 机器上编出未签名 IPA，装到手机上再用 LCSign 签名。
